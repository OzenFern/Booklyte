Module: reviewController

Controller for handling review-related operations. Interfaces with HTTP requests and responses and uses the reviewService to perform operations on reviews. Reviews are nested under library books with the following routes: GET /library/books/:id/review POST /library/books/:id/review PATCH /library/books/:id/review DELETE /library/books/:id/review
